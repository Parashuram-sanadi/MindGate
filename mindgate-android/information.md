# MindGate — Full System Functionality & Navigation Summary

MindGate is a comprehensive digital wellness platform that combines machine learning risk prediction with active usage monitoring and parental/educational oversight.

---

## 1. Core Functional Modules

### 1.1 Student Wellness & ML Pipeline
*   **AI Assessment**: A 34-question assessment analyzed by a **CatBoost** model to determine addiction risk levels.
*   **Danger Gates**: A secondary safety layer that validates "Severe" risk levels against physical and behavioral markers (loss of control, sleep disturbances, etc.).
*   **SHAP Explainability**: Identifies and displays the top 3 contributing factors (e.g., "Late Night Usage", "Stress Level") behind a student's risk score.
*   **Personalized Recommendations**: Dynamic advice generated by a recommendation engine based on specific risk indicators and score severity.

### 1.2 Digital Wellness Engine (Local-First)
*   **App Limit Monitoring**: Uses Android `UsageStats` and `AccessibilityService` to track app usage in real-time without requiring a backend connection.
*   **Hard-Block Overlay**: Instantly blocks access to specific apps once their daily time limit is reached.
*   **Wellness Puzzle (15-min Extension)**: Allows users to earn a one-time 15-minute extension by solving a cognitive puzzle, reinforcing self-regulation rather than just restriction.
*   **Study Mode**: Optional high-restriction period during academic hours.

### 1.3 Parent Monitoring System
*   **Asymmetric Linking**: Secure QR-based pairing where the **Student displays** a code and the **Parent scans** or manually enters it. Includes 10-minute expiry and 5-attempt brute-force protection.
*   **Usage Dashboards**: Parents view a real-time aggregate of their child's total usage vs. limit and an app-by-app breakdown.
*   **Throttled Notifications**: Parents receive "Limit Exceeded" alerts via a **20-minute cooldown bucket** mechanism to avoid notification fatigue.
*   **Privacy Guardrails**: Explicit allowlist schemas ensure parents *never* see raw assessment answers or psychological details.

### 1.4 Teacher Dashboard
*   **Batch Classification**: Teachers upload large datasets (CSV/XLSX) to classify an entire class's risk levels at once.
*   **Class Analytics**: Visual distribution of addiction risk across the student population (Low/Moderate/High/Severe).
*   **Performance Optimization**: Backend uses vectorized batch processing and single-pass SHAP calculations to handle datasets up to 2000 rows.

### 1.5 System Infrastructure
*   **JWT Authentication**: Secure token-based auth with an `AuthInterceptor` for all API calls.
*   **Dynamic Connection Settings**: Allows the backend API URL to be changed at runtime (critical for physical device testing on local networks) with a built-in TCP/HTTP health tester.
*   **Android 15 Compliance**: Fully aligned for **16KB page-size** support with NDK r28 and `targetSdk 35`.

## 2. Navigation Map (Screen by Screen)

### 2.1 Shared & Entry Screens
1.  **Splash Screen**: Evaluates session and routes to the appropriate dashboard.
2.  **Role Selection**: The root entry point for new or logged-out users to choose Student or Parent roles.
3.  **Connection Settings**: Reachable from the gear icon anywhere; configures the `API_BASE_URL` and runs diagnostics.
4.  **Auth (Login/Register)**: Unified JWT entry point. Registration includes a one-time role-selection gate.

### 2.2 Student Experience
1.  **Student Home (Dashboard)**: At-a-glance view of today's usage, active limits, current risk level, and primary recommendation.
2.  **Limits Tab**: List of all apps being monitored with their current time-spent vs. limit.
3.  **Assessment Tab**: Entry point to the 34-question AI wellness check.
4.  **Profile Tab**: History of previous risk scores and the entry point to "Link a Parent."
5.  **Assessment Flow**: Multi-step question journey with progress tracking.
6.  **Risk Result Screen**: The detailed AI report showing the risk level, pulsed "Severe" alerts, SHAP factors, and full recommendations list.
7.  **App Picker**: Searchable list of all installed apps to select which ones to restrict.
8.  **App Limit Setup**: Configuration screen for time limits, active days, and "Bedtime Lock."
9.  **Link a Parent**: Displays the secure QR code and manual `MG-XXXX` code with a live expiry countdown and automatic "Connected" detection.

### 2.3 Parent Experience (Monitor Mode)
1.  **Parent Dashboard**: List of all linked children showing their current status (Within Limit / Exceeded).
2.  **Link a Child**: Dual-mode screen with a live QR scanner (default) and a "Manual Entry" fallback with input normalization.
3.  **Child Usage Detail**: Full breakdown for a specific student, including total usage progress bars, per-app list, and a timeline of recent "Limit Exceeded" alerts.
4.  **Parent Alerts**: A unified chronological history of all notifications received from linked devices.

### 2.4 Teacher Experience
1.  **Teacher Dashboard**: High-level overview of class risk distribution and the primary "Upload Dataset" action.
2.  **Teacher Results**: A searchable/filterable list of all students processed in the last batch upload, including their risk levels and expanded views for individual SHAP indicators.

### 2.5 System Overlay Layer
1.  **Blocking Overlay**: A full-screen window that appears over blocked apps, preventing interaction.
2.  **Wellness Puzzle Activity**: The cognitive challenge screen launched from the block overlay to earn an extension.
